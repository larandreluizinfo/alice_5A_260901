# Agents

## Regras

- **Toda alteração feita no repositório DEVE ser commitada e enviada (push) ao GitHub imediatamente.** Não deixe alterações pendentes sem commit.
- Sempre faça commit com mensagens claras e descritivas.
- Antes de commitar, verifique o status com `git status` e o diff com `git diff`.
- Após cada commit, faça push ao remote.
